# Daylex

<!-- impeccable:product-schema 1 -->

## Platform

web

This record concerns the public presentation website, not the visual system of the Flutter client.

## Users

End users in professional studios, primarily on desktop computers and large screens. Tablet use in the app is secondary. The download website must be mobile-first: all platform choices visible immediately, including on phones. They should not need software-development vocabulary to understand the product or get started.

## Product Purpose

Daylex combines document drafting, conversational assistance, editing, preview and PDF export in one workspace. The website's primary conversion, confirmed by the owner, is downloading the desktop application.

## Capabilities and Constraints

Windows, macOS and Linux downloads are published automatically. A companion browser app is available at /app/. WhatsApp is desktop-only. Access is supplied by the studio's administrator; there is no verified public signup, price, free trial or sales contact to invent. Browser access needs its own credential; browser documents are local and do not automatically synchronize with desktop documents. AI services require connectivity. Current desktop packages are preview releases; installation can require explicit OS confirmation.

## Brand Commitments

The owner explicitly requests a substantial redesign: black and charcoal surfaces, pale blue/cyan and green accents, strong visual hierarchy, progressive disclosure and purposeful animation, inspired by the supplied TikTok Apps & Agents screenshot. Retain Daylex's name, not TikTok's symbols. Address end users with plain Italian. Keep API terminology, hashes, compiler dependencies and build metadata in technical documentation.

The owner requests a refined, futuristic, premium first impression and no speculative FAQ section. Windows 10 and 11 use the same qualified installer but have separate entry points. iPhone/iPad use the existing PWA, not an unsigned native iOS package. Browser installation must request user confirmation; use a native prompt where supported and an explicit guide elsewhere.

## Evidence on Hand

The working application, real public releases, the client's actual document templates and QA screenshots. No verified testimonials, adoption figures, speed measurements, pricing or certifications are supplied. Do not invent them. Show examples as examples, never as live AI results.

## Product Principles

- Lead with what the visitor can accomplish.
- Present Windows 11, Windows 10, macOS, Linux, iPhone/iPad and PWA immediately, with recognizable OS icons.
- Explain setup in ordinary language; retain truthful installation help.
- Keep release automation, existing downloads and the browser app working.
- Use movement to explain the document workflow; respect reduced motion.
